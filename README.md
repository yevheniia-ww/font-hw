# Fonts Homework

Невелика HTML/CSS-сторінка, зверстана за макетом. Сторінка містить текстові блоки, великі декоративні заголовки, бокові примітки та цитату. 

## Використано

* HTML5
* CSS3
* CSS Grid
* адаптивна верстка
* локальне підключення шрифтів через `@font-face`
* Google Fonts

## Шрифти

У проєкті використано:

* Kyiv Type Titling
* Raleway
